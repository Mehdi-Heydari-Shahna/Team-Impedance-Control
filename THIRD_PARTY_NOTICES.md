# Third-party assets

`assets/apollo/` contains the Apptronik Apollo model distributed through [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie). Its supplied Apache License 2.0 is retained at `assets/apollo/LICENSE`. Existing asset comments and notices are preserved.

The source README records that visual meshes were decimated using `teamimp/decimate.py`. The exact upstream revision was not recorded in the supplied archive. The asset files in this release preserve the uploaded bytes.

Scene textures are generated procedurally by `teamimp/textures.py`. No license for the authors' original research code was supplied; the asset license is not presented as a license grant for the rest of the project.
